# 📝 To-Do List Management System

## Overview

The **To-Do List Management System** is a desktop application developed in **C# using the .NET Framework**. It is designed to help users efficiently organize and manage their daily tasks through a simple and user-friendly interface. The project demonstrates the practical implementation of **Object-Oriented Programming (OOP)** principles, including encapsulation, inheritance, abstraction, and modular design.

The application allows users to create, update, delete, view, and track tasks while maintaining a clear separation between the presentation layer and business logic layer. The frontend is built using **Windows Forms**, while the backend functionality is implemented through a separate **Class Library (DLL)**, ensuring better maintainability and scalability.

---

## Features

### ✅ Add Tasks

Users can create new tasks by providing task details such as title, description, priority, or due date.

### ✏️ Update Tasks

Existing tasks can be modified whenever changes are required.

### ❌ Delete Tasks

Tasks that are no longer needed can be removed from the system.

### 📋 View Tasks

Users can view all tasks in an organized list for better task management.

### ✔️ Mark Tasks as Completed

Tasks can be marked as completed to track progress and productivity.

### 🔍 Task Status Management

The system distinguishes between pending and completed tasks, making it easy to monitor work progress.

### 🏗 Modular Architecture

The project separates frontend and backend logic through a dedicated Class Library DLL, promoting clean code and maintainability.

## OOP Concepts Implemented

### Encapsulation

Task-related data and operations are grouped within classes, protecting data integrity.

### Abstraction

Complex implementation details are hidden behind simple interfaces and methods.

### Inheritance

Classes can be extended and reused through inheritance where applicable.

### Polymorphism

Methods and objects can behave differently depending on their implementation.

### Separation of Concerns

Frontend and backend are separated to improve maintainability and code organization.

---

## System Architecture

### Frontend (Windows Forms)

* Handles user interactions.
* Displays task information.
* Provides forms and controls for task management.

### Backend (Class Library DLL)

* Contains business logic.
* Performs task operations such as add, update, delete, and complete.
* Manages task data processing independently from the UI.
